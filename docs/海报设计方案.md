# 《信息流知道你》宣传海报设计方案

> 内部执行文档。**只有一张海报**（原方案中的立牌、待机海报全部砍掉），它要独自完成"勾住 → 转化 → 信任"三件事。
> 对应策划案 7.2：海报 1 张，写真输出，预算数十元级。
> 正文（一~四章）是设计稿输入；附录是印制执行清单。

---

## 一、定位：一张海报，三级信息

没有立牌分担信息，这张海报必须自洽：3 米外能被标题勾住，走近能看到码扫码，扫之前扫一眼就知道"不收我信息"。

信息按阅读距离分三级，**从上到下刚好是"远 → 中 → 近"**：

| 级 | 内容 | 阅读距离 |
|----|------|----------|
| 一级（悬念） | 你刷了一会儿手机。它已经开始认识你了。 | 3~10 m |
| 二级（转化） | 体验二维码 + 约100秒 · 手机直接玩 · 免安装 | 0.5~1.5 m |
| 三级（信任） | 隐私三行 + 主题句收束 | 近距离细读 |

**挂放位置**：扫码入口旁或人流主来向，海报底部离地约 1.2 m（二维码高度在成人自然抬手范围内）。唯一的码就在这张海报上，点位宁缺毋滥。

## 二、共用视觉系统

### 2.1 色板（与 demo 大屏同一套语言）

| 角色 | 色值 | 用途 |
|------|------|------|
| 深底色 | `#0B1526` → `#101C31` 微渐变 | 海报背景 |
| 主高亮 | `#2A62BD` / `#4F8BE0` | 标题强调、画像进度条 |
| 点缀金 | `#C9A24A` | 只用在体验码描边上，全版面唯一金色落点 |
| 正文浅灰 | `#DFE5EF`（重点）/ `#93A0B4`（次要） | 文字层级 |

### 2.2 核心母题：我点了什么 → 它看到了什么 → 它推断出什么

不用雷达图、六边形、HUD 线框、锁头——那套元素会把项目拉回"网安宣传 PPT"。本装置真正的视觉资产是**"算法如何从行为推断人"本身**，纵向三段式直接画出来：

```
┌────────────────┐
│ ¥29.9 平价耳机   │   ← 我点了什么（真实信息流卡样式）
└───────┬────────┘
        ↓
   价格取向           ← 它看到了什么（燕大蓝进度条）
   ████████░░
        ↓
 「偏理性消费」        ← 它推断出什么（标签）
```

- 卡片是浅灰描边的真实信息流样式（取自 demo 手机端），向下引出燕大蓝进度条，再落到一枚标签；行为、信号、结论自上而下，观众不看文字也能读懂"它是从我干的事里推出来的"；
- 海报上的取景：**人形轮廓"描到一半"**——半透明信息流卡片群中，画像进度条正在逐条勾勒一个轮廓，描到一半停下。完整画像在装置里才发生，海报只给一半，问题留给现场。

### 2.3 文案红线

- **禁用 emoji**，icon 用细线几何图形（人形轮廓、光标轨迹、时钟+数据条）；
- **时间口径统一"约 100 秒"**（策划案：单人 100~120 秒），不出现"90 秒"，悬念句用"一会儿"避开具体时长；
- **删除口径统一"体验数据限时保存，最长 2 小时自动清除"**——不写"体验结束自动删除"（与真实架构不符），不写"可一键删除全部记录"（无身份标识的系统上这句话反而引出追问）；
- **"它"必须有视觉指代**：第二行"它已经开始认识你了"的视线落点处安排信息流标签/进度条元素（细小、半透明、不抢标题），让画面回答"它是谁"。若初稿发现易被读成 AI 助手或手机本身，加大标签元素的存在感；
- 承诺文字印发前与技术实现逐条核对，见附录 6.2。

### 2.4 字体

标题**思源黑体 Heavy**、正文思源黑体 Regular（免费可商用）；数字/代号用等宽体。交付印厂前全部转曲。

## 三、版式（60 × 90 cm，覆哑膜）

```
┌──────────────────────────┐
│ 顶部小字：国家网络安全宣传周    │
│          校园互动体验装置      │
│                            │
│ ① 一级标题（占版面 45%）：     │
│                            │
│    你刷了一会儿手机。          │
│    它已经开始认识你了。        │
│    （"它"字视线落点处：半透明   │
│     信息流标签群 + 进度条）     │
│                            │
│ ② 中部视觉（占 25%）：         │
│    人形轮廓正由画像进度条       │
│    逐条"描"出来——描到一半      │
│                            │
│ ③ 体验码（约 9cm，金色描边）   │
│    扫码立即体验                │
│    约100秒 · 手机直接玩 · 免安装│
│                            │
│ ④ 隐私三行（线性 icon，小）：   │
│   [身份] 不需要姓名、手机号     │
│   [行为] 只分析本次点击行为     │
│   [数据] 最长2小时自动清除      │
│                            │
│ ⑤ 底部通栏（主题句收束）：      │
│    数据画像，不是你本人。        │
│    + 燕山大学 落款             │
└──────────────────────────┘
```

- **二维码 ≥ 9cm**（60cm 版面上约 1/6 宽）。海报底边离地 1.2 m 时，码心高度约 0.9~1 m，可扫；旁配**公网链接文字版**（域名定稿后填入）兜底；
- 公众号码**不放**：单张海报只留一个行动点，避免双码竞争；公众号沉淀由书签承担（书签印公众号码，见策划案口径差异表）；
- 隐私三行缩小置底是刻意的：它不是扫码前的门槛，而是犹豫者的信任背书；讲解员指这五行即可完成告知（对应策划案 4.1 首屏三句话）；「不上大屏」由现场讲解口头说明，不占版面；
- 底部主题句是全套传播的收束位：观众体验完抬头回看海报，正好读到"数据画像，不是你本人。"

# 附录：印制与执行清单（内部，做完设计稿再看）

## 6.1 印制规格与验收

| 项 | 要求 |
|----|------|
| 源文件 | 60 × 90 cm 实际尺寸 1:1 制作；文字与图形保持矢量，交付前转曲 |
| 位图 | ≥ 150 dpi（版面有细线、小字、二维码，低分辨率会糊） |
| 二维码 | 原始矢量文件（SVG/PDF）置入，**禁止位图缩放** |
| 交付 | PDF/X 或 300 dpi JPG 给印厂；自留可编辑源文件，D-3 前可改文案 |
| 覆膜 | 哑膜（远看不反光） |
| 二维码验收 | iOS / Android 各 2 台，0.5 / 1 / 1.5 m 三档，**哑膜打样后试扫** |

## 6.2 承诺文案技术核对表（印发前逐条确认）

| 物料承诺 | 依据 | 核对项 |
|----------|------|--------|
| 不需要姓名、手机号 | 6.2 | 代码中无任何身份字段输入点；告知页文案与之一致 |
| 只分析本次点击行为 | 6.2 | 采集清单 = 点击/停留/滑动事件 + 准/不准反馈 + 派生分数 |
| 最长 2 小时自动清除 | 6.2 | 会话数据仅内存运行、TTL=2h 实测生效；不记录 IP、无设备指纹 |

## 6.3 时间节点（对齐策划案 7.1 倒排表）

- **D-14**：域名批复 → 本方案终稿；
- **D-7**：文案终稿 + 二维码真机测试通过 → 送印；
- **D-3**：到货验收（尺寸、色差、二维码复扫）；
