# 信息流知道你

燕山大学 2026 年国家网络安全宣传周校园互动体验装置：扫码进入模拟信息流，
正常点击、停留、划过几分钟，一旁的大屏同步"生长"出你的兴趣画像并展示
推断依据——随后揭示全过程没有输入任何个人信息，并引导完成一次真实可
操作的隐私练习（关闭个性化推荐、清理记录、一键删除本次数据）。

全部白盒规则、零第三方依赖、断网可跑；会话与画像只存在内存，跨重启仅
保留白名单内的匿名聚合数字。

## 目录结构

```
├── demo/                 可运行 demo（引擎 / 服务端 / 三端页面 / 仿真校准）
│   ├── engine.py         画像引擎、收敛策略、证据链、投放、广告匹配
│   ├── server.py         stdlib HTTP + SSE，全部路由
│   ├── simulate.py       蒙特卡洛仿真与参数校准（§8.9）
│   └── static/           手机端 / 大屏 / 后台三个页面
├── 事件库/               内容种子库（134 卡 + 24 广告 + 分类学 + QA 脚本）
├── docs/                 策划案、开发方案、内容库设计、界面/海报/配色方案
├── deploy/               systemd 服务单元与部署说明
└── knowledge/            预留知识库（当前未使用）
```

## 快速开始

```bash
cd demo
uv run server.py            # 或 python3 server.py，零第三方依赖
```

启动后终端会打印三个地址：手机端 `/`、大屏 `/screen`、后台 `/admin`
（首启随机生成管理员密钥，或用环境变量 `YUNA_ADMIN_PASSWORD` 固定）。
参数校准与部署说明见 `demo/README.md` 与 `deploy/README.md`。

## 设计边界

- 数据最小化：不采集姓名、手机号、IP、设备指纹与任何账号标识
- 白盒可解释：每条结论可下钻到原始行为，无黑箱模型
- 限时删除：单次会话 2 小时自动过期，结果页可立即手动删除
- 内容红线：机器校验 + 人工审核双通道，全部内容为模拟内容
