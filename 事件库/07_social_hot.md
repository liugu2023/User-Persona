## H02 一场社团展演为什么值得认真做
- 域 社交热点｜长度 L｜标签 club 1.0 / campus_life 0.7｜特质 价优 1.0 / 深读 0.7
- 审核：pending
- 摘要：灯光、动线、主持节奏，会决定观众留下多久。
- 正文：很多人把社团展演理解成“节目排出来就行”，真正影响体验的却是细节。灯光太亮，舞台层次会被抹平；音量忽大忽小，观众很快出戏；主持串词如果只负责报幕，节目之间就会断成一截一截。做得讲究一点，不是为了显得高级，而是让台下的人愿意多停留十分钟。

  预算有限时，最该优先的是动线和节奏。入口要一眼看见签到位置，节目单最好能扫码查看，观众离场时不要和候场人员撞在一起。主持人的任务也不是讲笑话，而是在每个节目之前给一个进入情绪的理由。哪怕设备普通，只要节奏顺，展演就不会散。

  这类活动的价值不只在当天。一次认真完成的展演，会留下照片、视频、流程表和复盘记录，下一届接手时不必从零开始。品质感不是花大钱堆出来的，而是每个环节都有人负责。复盘时把最卡的三处写下来，比单纯夸“很成功”更有用。 如果时间允许，还可以提前做一次空场走位：主持人从哪里上台，观众从哪里进出，设备线藏在哪里，全部走一遍，正式演出时就少一半慌乱。

## H03 一个热梗怎么变成校园议题
- 域 社交热点｜长度 L｜标签 trend 1.0 / news_literacy 0.7｜特质 深读 1.0 / 专业 0.7
- 审核：pending
- 摘要：从群聊表情到线下讨论，中间发生了什么。
- 正文：热梗最开始往往只是群聊里的一个表情或一句改写，真正变成校园议题，要经历几次转场。第一次是从熟人群转到公开平台，语境被稀释，玩笑开始被不同的人重新解释。第二次是从线上转到线下，海报、活动标题、课堂讨论都会借用它，原本轻松的表达就带上了观点。第三次是反向传播：有人开始解释这个梗“到底什么意思”，它就从玩笑变成了可讨论对象。

  理解这个过程，比判断一个梗好不好笑更重要。很多误会都发生在语境迁移时：A 群里默认大家知道背景，B 平台上的路人却只看到一句话。传播越快，省略的上下文越多。于是同一个表达，有人觉得亲切，有人觉得冒犯，有人完全看不懂。

  下次看到一个校园热词突然刷屏，不妨先问三件事：它从哪里来，谁在使用它，被谁误解了。热点不是凭空出现的，它只是把原本分散的情绪集中照亮了一下。先补上下文，再决定要不要跟着转发。

## H07 志愿活动排班表怎么做才不乱
- 域 社交热点｜长度 L｜标签 volunteer 1.0 / campus_life 0.7｜特质 专业 1.0
- 审核：pending
- 摘要：岗位、时段、替补和交接，要在活动前讲清楚。
- 正文：志愿活动最容易乱在排班，而不是现场。表格里如果只写姓名和时间，到了现场一定会有人问“我具体做什么”。一张合格的排班表至少有四列：岗位、时段、负责人、交接说明。签到岗要知道物料在哪里，秩序岗要知道什么时候引导排队，机动岗要知道谁有权临时调人。

  替补也必须提前写进表里。很多活动默认“临时再说”，结果一旦有人迟到，所有人都在群里找人。更稳的做法是每个关键岗位配一个备用人，并写清替补触发条件：迟到十分钟、临时离场、现场人流超过预估，都应该自动换人。

  活动结束后还要留一份复盘，不写情绪，只写事实：哪个时段人最多，哪个岗位任务不清，哪些物料多了或少了。下一次活动如果能少问一半问题，这次排班才算真正有效。复盘表越具体，后来的人越省力。 如果现场有临时变化，也不要只在群里喊一句，最好同步改表，让后来接班的人看到同一份最新版本。

## H10 两种社团招新方案，哪种更容易留下人
- 域 社交热点｜长度 L｜标签 club 1.0｜特质 对比 1.0 / 大众 0.7
- 审核：pending
- 摘要：热闹型和体验型对比，目标不同，做法也不同。
- 正文：社团招新常见两种方案：一种把摊位做得热闹，海报醒目、小游戏多、奖品摆满；另一种把体验做深，安排十分钟真实任务，让新同学提前感受社团平时怎么运转。前者吸引路过的人，后者筛出真正愿意留下的人，不能简单说谁更好。

  如果目标是扩大知名度，热闹型更有效。它降低参与门槛，让陌生人愿意停下脚步，适合刚恢复活动或缺少曝光的社团。问题是报名表会很漂亮，实际到场率可能不高。体验型相反，现场看起来没那么炸，但参与者更清楚自己要加入什么，后续流失少。

  比较稳的组合是先热闹引流，再用小任务做二次确认。第一天让人知道你，第二天让人试着做一件真实的事。招新不是收集联系方式，而是让双方都少一点误会。最后复盘别只看报名数，还要看两周后的留存。 还要注意别把所有资源都花在第一天，真正决定留下来的，往往是第二次活动有没有人继续跟进安排。

## H11 看到校园通知截图，先做三步核验
- 域 社交热点｜长度 L｜标签 news_literacy 1.0 / campus_notice 0.7｜特质 深读 0.7 / 保守 1.0
- 审核：pending
- 摘要：来源、时间、原文链接，三步过滤大部分误传。
- 正文：校园通知截图最容易被转发，也最容易过期。核验时先看来源：是否来自学院、部门或活动主页，而不是二次截图。再看时间：很多通知隔了几天，地点和截止时间已经改过。最后找原文链接，截图里少掉的备注，往往才是关键。

  如果找不到原文，不要急着继续转发。可以在群里补一句“来源待确认”，或者只把它当作提醒去查官网。截图天然会丢上下文，尤其是报名条件、人数限制、材料要求这些细节。少转一次不确定的信息，比事后解释强。

  信息素养不是怀疑一切，而是知道什么需要多看一眼。越是和大家相关的通知，越值得慢半拍。遇到标题很急、措辞很满的截图，更要先停一下：真正重要的信息，通常经得起你多查一分钟。 核验完成后再转发，也尽量附上原链接，让后来看到的人可以自己判断，而不是只依赖你的截图。遇到多个版本同时流传时，把差异列出来，比急着给结论更稳。
